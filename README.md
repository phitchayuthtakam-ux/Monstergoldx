# วิธีติดตั้ง MonsterGoldX ลงมือถือ

ใช้เวลาประมาณ 15 นาที ทำครั้งเดียวจบ ไม่มีค่าใช้จ่าย

---

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.webmanifest` | บอกมือถือว่าชื่อแอป ไอคอน สีอะไร |
| `sw.js` | ทำให้เปิดแอปได้แม้ไม่มีเน็ต |
| `icon-180/192/512.png` | ไอคอนแอป |
| `icon-512-maskable.png` | ไอคอนสำหรับ Android |
| `.nojekyll` | ไฟล์เปล่า จำเป็นสำหรับ GitHub Pages |

**ต้องอัปโหลดทุกไฟล์ และห้ามเปลี่ยนชื่อไฟล์**

---

## ขั้นที่ 1 — สมัคร GitHub

1. เข้า github.com กด **Sign up**
2. สมัครด้วยอีเมล ตั้งชื่อผู้ใช้ (จำไว้ จะใช้ในลิงก์)
3. ยืนยันอีเมล

---

## ขั้นที่ 2 — สร้างที่เก็บไฟล์

1. กดปุ่ม **+** มุมขวาบน → **New repository**
2. ตั้งชื่อ `monstergoldx`
3. เลือก **Public** (ต้องเป็น Public ถึงจะใช้ Pages ฟรีได้)
4. กด **Create repository**

> Public แปลว่าใครก็เห็นโค้ดได้ แต่ **ข้อมูลน้ำหนักและอาหารของคุณไม่ได้อยู่บน GitHub** มันเก็บอยู่ในเครื่องคุณเท่านั้น

---

## ขั้นที่ 3 — อัปโหลดไฟล์

1. ในหน้าที่เพิ่งสร้าง กด **uploading an existing file**
2. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้เข้าไป (เลือกทั้งหมดพร้อมกันได้)
3. เลื่อนลงล่าง กด **Commit changes**

> ถ้า `.nojekyll` ลากไม่เข้าเพราะเป็นไฟล์ซ่อน: กด **Add file → Create new file** พิมพ์ชื่อ `.nojekyll` แล้วกด Commit โดยไม่ต้องใส่เนื้อหา

---

## ขั้นที่ 4 — เปิด GitHub Pages

1. ในหน้า repository กด **Settings** (แถบบน)
2. เมนูซ้าย เลือก **Pages**
3. หัวข้อ **Source** เลือก **Deploy from a branch**
4. **Branch** เลือก `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–3 นาที รีเฟรชหน้า จะขึ้นลิงก์สีเขียว

ลิงก์จะเป็นแบบนี้:

```
https://ชื่อผู้ใช้ของคุณ.github.io/monstergoldx/
```

---

## ขั้นที่ 5 — ติดตั้งลงหน้าจอโฮม

### iPhone (ต้องใช้ Safari เท่านั้น)

1. เปิดลิงก์ใน **Safari** (Chrome บน iPhone ติดตั้งไม่ได้)
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น ตรงกลางแถบล่าง)
3. เลื่อนหา **เพิ่มไปยังหน้าจอโฮม**
4. กด **เพิ่ม**

### Android

1. เปิดลิงก์ใน Chrome
2. กดจุดสามจุดมุมขวาบน → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**

เสร็จแล้วจะได้ไอคอนวงกลมรอยเล็บสีส้มบนหน้าจอ เปิดแล้วเต็มจอ ไม่มีแถบเบราว์เซอร์ ใช้ได้แม้ไม่มีเน็ต

---

## เรื่องที่ต้องรู้เรื่องข้อมูล

**ข้อมูลเก็บอยู่ในเครื่องคุณเครื่องเดียว** ไม่ได้ขึ้นคลาวด์ แปลว่า:

- เปลี่ยนมือถือ = ข้อมูลไม่ตามไป
- ลบแอปออกจากหน้าจอโฮม = ข้อมูลอาจหาย
- ล้างข้อมูลเบราว์เซอร์ = ข้อมูลหาย

**ดังนั้นต้องส่งออกสำรองทุกต้นเดือน** ที่แท็บแผน → สำรองข้อมูล → ส่งออก แล้วคัดลอกข้อความส่งเข้าอีเมลตัวเอง หรือเซฟไฟล์ไว้ใน Files/Google Drive

ถ้าย้ายเครื่อง: เปิดแอปบนเครื่องใหม่ → แท็บแผน → สำรองข้อมูล → วางข้อความที่สำรองไว้ → กดนำเข้า

---

## เวลาจะแก้แอปในอนาคต

1. เข้า repository บน GitHub
2. กดที่ไฟล์ `index.html` → กดรูปดินสอ (Edit)
3. แก้แล้วกด Commit changes
4. รอ 1–2 นาที แล้วเปิดแอปใหม่

ถ้าเปิดแล้วยังเป็นเวอร์ชันเก่า ให้ปิดแอปจากหน้าจอแล้วเปิดใหม่ (แอปโหลดเวอร์ชันใหม่จากเน็ตทุกครั้งที่เปิด แต่ถ้าไม่มีเน็ตจะใช้เวอร์ชันที่เก็บไว้)

---

## ถ้าเปิดลิงก์แล้วขึ้น 404

- รอให้ครบ 3 นาทีหลังกด Save ใน Pages
- ตรวจว่าไฟล์ชื่อ `index.html` ตัวเล็กทั้งหมด
- ตรวจว่าไฟล์อยู่ชั้นนอกสุดของ repository ไม่ได้อยู่ในโฟลเดอร์ย่อย

## ถ้าติดตั้งแล้วแต่เปิดไม่ได้ตอนไม่มีเน็ต

เปิดแอปตอนมีเน็ตหนึ่งครั้งก่อน เพื่อให้ระบบเก็บไฟล์ไว้ในเครื่อง แล้วค่อยลองใหม่

---

## ทางเลือกอื่นถ้าไม่อยากใช้ GitHub

- **Netlify Drop** — netlify.com/drop ลากโฟลเดอร์นี้ทั้งโฟลเดอร์ทิ้งลงไป ได้ลิงก์ทันที ไม่ต้องสมัครก็ได้
- **Cloudflare Pages** — ขั้นตอนคล้าย GitHub Pages

ทั้งสองอย่างฟรีและได้ HTTPS เหมือนกัน ซึ่งจำเป็นสำหรับการติดตั้งลงหน้าจอโฮม
